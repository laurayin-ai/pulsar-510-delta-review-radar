# Pulsar 510 Delta Review Radar

Static archive and product-feedback analysis for public reviews of the Pulsar 510 Delta 3-in-1 Vaporizer Kit.

The website source is `dist/index.html`. GitHub Pages deployment is handled by `.github/workflows/pages.yml`.

Data boundaries:

- Review volume is not treated as sales volume or defect rate.
- Missing reviewer avatars remain missing; initials are displayed instead.
- User statements, analytical inference, and R&D verification recommendations are kept separate.
